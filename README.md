# 画布 · AI 图像工作台 (AI Image Studio)

> 单文件多提供商 AI 生图工具 · Cupertino 设计 · 图片本地永久化

一个**零依赖、单文件（index.html）**的 AI 图像生成工作台，直接在浏览器打开即可使用。支持多个提供商（grsai 中转、OpenAI 兼容接口），图片生成后**自动下载为 base64 永久存入浏览器本地**，不会因 CDN 链接过期而消失。

## ✨ 核心特性

### 🎨 生成能力
- **文生图 / 图生图**：支持 grsai（含 nano-banana 系列 4K）、OpenAI 兼容 `/images/generations`、`/images/edits` 接口
- **多提供商分组管理**：API 地址、Key、模型列表、编辑端点均可配置，支持一键合并重复提供商
- **参数控制**：比例（1:1 / 3:2 / 16:9 / 21:9 / 9:16…）、分辨率（1K / 2K / 4K）、质量、张数、Seed、负面提示词、图生图强度
- **异步任务**：grsai 长任务轮询，任务 ID 持久化，断网后点"重试"可继续找回结果
- **并发队列**：最多 2 个任务并行，排队/停止/重试/失败原因一目了然

### 💾 图片永久化（round19 核心修复）
- 生成后立即把远程 URL **下载转 base64** 存入 `localStorage`，CDN 链接过期也不丢图
- 大图智能压缩（>320KB 探测尺寸，转 JPEG q=0.82、最长边 1600px），防撑爆 5MB 存储上限
- 历史存量 URL 图打开广场时自动迁移，失败标记不重试防死循环
- 80 张上限 + 超限自动清理最早 1/3 + 存储用量实时监控

### 🖼️ 画廊与体验
- **广场**：按日期分组、关键词搜索、文生图/图生图/失败筛选、多选对比/打包下载/合并去重、**删除后 5 秒可撤销**
- **大图预览**：左右滑动/键盘切换、滚轮/双击/pinch 缩放、缩放后拖拽平移
- **画板编辑器**：画笔/橡皮标记红色区域（图生图局部修改）、撤销/清空
- **真实分辨率**：生成后异步探测并持久化图片真实像素尺寸，三处展示
- **生成来源追溯**：每张图记录提供商·分组，卡片/预览/缩略图三处可见

### 🎛️ Cupertino 设计（round18）
- 全套 iOS 风格：毛玻璃顶栏/Tab Bar、蓝色圆角主按钮、chip/pill、Alert 对话框、照片查看器、滑动开关、range 滑块、胶囊 toast
- **深色模式跟随系统**（手动设置优先，无设置时自动跟随 `prefers-color-scheme`）

### ♿ 无障碍与细节
- 全部模态支持 **Esc 关闭**（含对话框、编辑器）
- toast 可点击关闭、Ctrl/⌘+Enter 快速生成、快捷键提示
- 应用内对话框替换原生 confirm/prompt、错误信息胶囊条、搜索清除按钮

## 🚀 使用

1. 打开 `index.html`（任意静态服务器，如 `python3 -m http.server 4173`）
2. 进入「设置」→ 添加提供商（grsai 中转或任意 OpenAI 兼容地址）+ 分组 Key
3. 回「工作台」输入提示词 → 生成
4. 生成的图自动永久保存在浏览器本地，可在「广场」浏览/管理

> ⚠️ API Key 仅保存在**浏览器 localStorage**，不写入代码、不上传服务器。

## 📦 技术说明

- 纯 HTML/CSS/JS 单文件，**零构建、零依赖、零后端**
- 存储：`localStorage`（画廊 `canvasGalleryV2`，任务队列 `canvasTasksV2`）
- 兼容：grsai `/api/generate` + `/api/result` 轮询；OpenAI `/images/generations`、`/images/edits`
- 已累计 51+ 项功能/修复迭代（round15-20）
